## 📖 Descripción

Este repositorio contiene una colección completa de **más de 30 ejercicios prácticos** desarrollados durante el módulo de **Desarrollo de Interfaces Web (DIW)** del ciclo formativo de Desarrollo de Aplicaciones Web.

Los ejercicios cubren desde fundamentos de HTML y CSS hasta técnicas avanzadas con SASS, animaciones, mapas de imagen responsivos y manipulación del DOM con JavaScript.

### 🎓 Contexto Educativo
- **Nivel**: Ciclo Formativo de Grado Superior
- **Módulo**: Desarrollo de Interfaces Web (DIW)
- **Tecnologías**: HTML5, CSS3, SASS, JavaScript, jQuery
- **Enfoque**: Diseño responsive y accesibilidad web

## 🚀 Cómo Usar

### 1️⃣ Clonar el repositorio

```bash
git clone https://github.com/albertogarciaquintana5-jpg/DIW-Interfaces-Web.git
cd DIW-Interfaces-Web
```

### 2️⃣ Abrir ejercicios

Simplemente abre cualquier archivo `.html` en tu navegador favorito:

```bash
# Con Live Server en VS Code
# Haz clic derecho → Open with Live Server

# O directamente
open ejercicios/html-basico/02-02.html
```

### 3️⃣ Compilar SASS (opcional)

Si quieres modificar los archivos SASS:

```bash
# Instalar SASS globalmente
npm install -g sass

# Compilar SASS a CSS
sass sass/practica-vscode.scss css/practica-vscode.css --watch
```
