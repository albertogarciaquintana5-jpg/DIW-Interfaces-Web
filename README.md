## 🚀 Instalación

### Requisitos

```bash
✅ Navegador moderno (Chrome, Firefox, Edge)
✅ Editor de código (VS Code recomendado)
✅ Live Server (extensión VS Code)
✅ SASS compiler (opcional)
```

### Inicio rápido

```bash
# 1. Clonar repositorio
git clone https://github.com/albertogarciaquintana5-jpg/DIW-Interfaces-Web.git
cd DIW-Interfaces-Web

# 2. Abrir ejercicios
# Opción A: Doble clic en cualquier .html
# Opción B: Con Live Server en VS Code

# 3. Compilar SASS (opcional)
npm install -g sass
sass --watch practica-vscode.scss:practica-vscode.css
```
