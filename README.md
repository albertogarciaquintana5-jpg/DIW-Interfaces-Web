## 📖 Descripción

Bienvenido a la **colección completa de ejercicios prácticos** del módulo **Desarrollo de Interfaces Web (DIW)** del Ciclo Formativo de Grado Superior en **Desarrollo de Aplicaciones Web (DAW)**.

Este repositorio contiene **más de 30 ejercicios prácticos** que cubren los fundamentos y técnicas avanzadas de:

- 🌐 **HTML5** - Estructura semántica y multimedia
- 🎨 **CSS3** - Estilos avanzados y layouts modernos
- 💅 **SASS/SCSS** - Preprocesadores CSS
- ⚡ **JavaScript** - Interactividad y manipulación del DOM
- 📱 **Diseño Responsive** - Mobile-first approach
- ♿ **Accesibilidad Web** - WCAG y ARIA
- 🗺️ **Mapas de imagen interactivos** - Responsive image maps
- ✨ **Animaciones CSS** - Efectos visuales modernos

## 🚀 Instalación y Uso

### ✅ Requisitos

```bash
✅ Navegador moderno (Chrome 90+, Firefox 88+, Safari 14+, Edge 90+)
✅ Editor de código (VS Code recomendado)
✅ Live Server (extensión de VS Code - opcional)
✅ SASS compiler (opcional para editar archivos .scss)
```

### 🎯 Inicio rápido

```bash
# 1. Clonar el repositorio
git clone https://github.com/albertogarciaquintana5-jpg/DIW-Interfaces-Web.git
cd DIW-Interfaces-Web

# 2. Abrir ejercicios
# Opción A: Doble clic en cualquier archivo .html
# Opción B: Con Live Server en VS Code
#   → Clic derecho en archivo .html
#   → Seleccionar "Open with Live Server"

# 3. Compilar SASS (opcional - solo si editas archivos .scss)
npm install -g sass
sass --watch practica-vscode.scss:practica-vscode.css
```

### 💡 Navegación

- Los archivos `.html` están numerados secuencialmente (ej: 02.02, 02.03...)
- Abre cualquier archivo directamente en tu navegador
- Los ejercicios son independientes entre sí
- Consulta los comentarios en el código para entender cada ejercicio

## 💡 Temas cubiertos

### 🌐 HTML5

- ✅ **Estructura semántica** - `<header>`, `<nav>`, `<main>`, `<footer>`, `<article>`, `<section>`
- ✅ **Formularios HTML5** - Input types, validación, atributos required/pattern
- ✅ **Multimedia** - `<audio>`, `<video>`, controles nativos
- ✅ **Canvas y SVG** - Gráficos vectoriales y bitmap
- ✅ **APIs HTML5** - LocalStorage, Geolocation, Drag & Drop

### 🎨 CSS3

- ✅ **Selectores complejos** - Combinadores, atributos, nth-child
- ✅ **Pseudo-clases y pseudo-elementos** - `:hover`, `:focus`, `::before`, `::after`
- ✅ **Flexbox layout** - Flex containers y flex items
- ✅ **CSS Grid** - Grid template, areas, tracks
- ✅ **Media queries** - Responsive breakpoints
- ✅ **Animations y Transitions** - Animaciones fluidas
- ✅ **Transform y Filter** - Transformaciones 2D/3D, filtros

### 💅 SASS/SCSS

- ✅ **Variables** - `$color`, `$size` para reutilización
- ✅ **Nesting** - Anidación de selectores
- ✅ **Mixins** - `@mixin` y `@include` para código reutilizable
- ✅ **Extends** - `@extend` para herencia de estilos
- ✅ **Funciones** - Operaciones matemáticas y de color
- ✅ **Partials e imports** - Organización modular del código

### ⚡ JavaScript

- ✅ **Selección de elementos** - `querySelector`, `getElementById`
- ✅ **Event listeners** - `addEventListener`, event handling
- ✅ **AJAX requests** - Fetch API, XMLHttpRequest
- ✅ **LocalStorage** - Persistencia de datos en cliente
- ✅ **Responsive images** - Manipulación dinámica de imágenes

### 📱 Diseño Responsive

- ✅ **Mobile First approach** - Diseño desde móvil hacia desktop
- ✅ **Breakpoints** - Puntos de quiebre estándar
- ✅ **Flexible layouts** - Porcentajes, fr, auto
- ✅ **Responsive images** - `srcset`, `sizes`, `<picture>`
- ✅ **Touch-friendly UI** - Interfaces táctiles optimizadas
